From talk to work. Same afternoon.

Dictum is built for the person who leaves the meeting with the homework. Everything it produces points back to the exact second someone said it.

Specs

A desktop app, not a tab.

One installer. The first run downloads the models it needs for your machine and asks for the two permissions it uses: the microphone and system audio.

Mac

macOS 14.2 or later, Apple silicon.

16 GB of memory runs everything locally. 32 GB unlocks the larger Qwen models.

Windows

Windows 10 or later, 64-bit.

A GPU speeds transcription up; it is not required.

Speech

GigaAM v3 for Russian, 0.4 GB. GigaAM multilingual, 2.2 GB.

Speaker separation with pyannote.

Language models

Gemma 4 12B, Qwen 3.5 4B and 9B, Qwen 3.6 35B, Qwen 3.8 27B, all run locally.

Claude in the cloud with your own key.

Integrations

Jira and Confluence over a browser sign-in. Word, Markdown and ZIP exports. Project files that move between machines.

Price

Free. The source is on GitHub.

No account, no telemetry, no seat.
